## 테스트 개요
- 테스트 스크립트: `tools/tests/ws-smoke.mjs`
- 목적: 관리자 클라이언트가 `PING_TEST`를 `ALL` 대상으로 브로드캐스트하면, 수집 노드(플러그인)가 이를 수신하고 `PONG_RESPONSE`를 서버로 전송하며, 서버는 해당 응답을 관리자 클라이언트로 중계하는지 검증.

## 실행 결과
- 관리자 및 플러그인 간의 브로드캐스트 수신(관리자 → ALL → 플러그인) 확인: 성공
- 플러그인의 응답(`PONG_RESPONSE`)이 서버에 도달하고 관리자에게 중계되는지 확인: 성공
- 해당 검증을 위한 테스트 스크립트가 추가되었으며 로컬에서 실행되어 정상 동작을 확인함.

## 관련 변경
- `server/src/index.ts`: 브로드캐스트(PING_TEST target: ALL) 우선 중계 처리 추가 및 `PONG_RESPONSE`를 관리자 클라이언트로 중계하는 로직을 추가하여 관리자 UI가 응답을 수신하도록 개선.
- `tools/tests/ws-smoke.mjs`: E2E 스모크 테스트 추가 (관리자/플러그인 WS 클라이언트 시뮬레이션).

---

## 재현 방법 (개발자 로컬)
1. 서버 실행: `node server/dist/index.js`
2. 테스트 실행: `node tools/tests/ws-smoke.mjs`
3. 기대 결과: 콘솔 출력 상에서 관리자 클라이언트가 `PONG_RESPONSE`를 수신함을 확인
