# R-00440 docs/rule/R-00440 plugin-ui-ux.md

본 문서는 `WebCrawlServer` 프로젝트의 브라우저 확장 플러그인 UI/UX 디자인 지침입니다. 팝업 UI 레이아웃, 탭 스위칭 네비게이션, 마우스 드래그 크기 조절, 텍스트 선택 허용 및 시각적 상태 피드백 체계를 정의합니다.

---

## 1. 디자인 기본 원칙 및 테마

1.1 **테마 기준**: 다크 테마 다크 투톤 스타일 적용 (기본 배경: `#0d131f`, 카드 배경: `#162032`, 강조색: `#38bdf8` / `#1d4ed8`)  
1.2 **타이포그래피**: 기본 본문 `Noto Sans KR`, 폰트 및 노드 ID/로그 표현용 `JetBrains Mono` / `monospace` 조합  
1.3 **아이콘 시스템**: Google Material Symbols Outlined 사용 (`popup.html` CDN 태그로 로드하여 레이아웃 깨짐 방지)  

---

## 2. 팝업 레이아웃 및 탭 스위칭 구조

팝업 UI는 상단 헤더, 탭 네비게이션 바, 탭별 콘텐츠 영역, 하단 푸터로 명확히 구조화되어야 합니다.

```
+------------------------------------------+
|  [icon] WebCrawlServer basic             |  <- Header
+------------------------------------------+
|  [ 기본 ]  |  [ 정보 ]  |  [ 디버깅 ]    |  <- TabBar
+------------------------------------------+
|                                          |
|  ( 탭별 콘텐츠 영역: Basic / Info / Debug ) |  <- TabContent (overflow-y: auto)
|                                          |
+------------------------------------------+
|  노드 ID: f47ac10b-58cc...               |  <- Footer
|  포트: 9600                               |
+------------------------------------------+
```

### 2.1 상단 헤더 (Header)
- 타이틀: **`WebCrawlServer basic`** 명시 (불필요한 과장 서브 문구 배제)

### 2.2 탭 스위칭 구조 (TabBar & Tabs)
- **`기본` 탭**:
  - WebSocket 실제 연결 상태 카드 (온라인: `#34d399` / 오프라인: `#f87171`)
  - 현재 활성 탭 URL 표시 카드
  - DOM 수집 및 전송 메인 버튼 ("WebCrawlServer로 전송")
  - 처리 상태 메시지 피드백 바
- **`정보` 탭**:
  - 브라우저 환경 정보: 플랫폼, 언어, 벤더, 네트워크 상태, User-Agent
  - 브라우저 프로세서 정보: 논리 CPU 코어 수, 디바이스 메모리, 최대 터치 포인트
- **`디버깅` 탭**:
  - 서버 송신용 커스텀 JSON 포맷 작성 텍스트에리어 (`textarea`)
  - 보내기 버튼 및 전송 처리 상태 문구
- **하단 푸터 (Footer)**:
  - 크롬 스토리지의 실제 노드 ID(`clientId`) 표출 (드래그 복사 가능)
  - 통신 포트 번호(`9600`) 표출

---

## 3. 마우스 드래그 크기 조절 매커니즘 (`resize`)

크롬 확장 프로그램 팝업 창은 내부 컨테이너 크기에 맞춰 브라우저 외곽 프레임이 자동 조절됩니다.

3.1 **리사이즈 속성 적용**: 최상위 컨테이너(`.popup-container`)에 `resize: both; overflow: auto;` 속성을 지정하여 우측 하단 핸들을 통한 마우스 드래그 크기 변경을 지원해야 합니다.  
3.2 **규격 제한**:
   - **기본 가로/세로**: 360px × 480px (빌드 상수로 초기화)
   - **최소 가로/세로**: 320px × 420px (`min-width`, `min-height`)
   - **최대 가로/세로**: 600px × 700px (`max-width`, `max-height`)
3.3 **유연한 레이아웃 (Flexbox)**: 팝업 크기 변경 시 헤더/탭바/푸터는 고정(`flex-shrink: 0`)되고, 본문 영역(`tab-content`)이 수직 확장(`flex: 1`, `overflow-y: auto`)되어 레이아웃 깨짐을 방지해야 합니다.

---

## 4. 텍스트 드래그 선택 및 복사 지원 (`user-select`)

4.1 **전역 드래그 차단 금지**: `body`나 최상위 컨테이너에 `user-select: none;`을 전역 적용하는 것을 금지합니다.  
4.2 **선택 허용 대상**: 노드 ID, 현재 URL, User-Agent 문자열, 디버그 텍스트에리어, 로그 메시지 등 주요 정보 영역은 마우스 드래그 선택 및 복사(`user-select: text`)가 보장되어야 합니다.  

---

## 5. 시각적 상태 피드백

5.1 **온라인/오프라인 인디케이터**:
   - 온라인 상태: 초록색 애니메이션 펄스 배지(`bg-emerald-400 animate-pulse`)
   - 오프라인 상태: 빨간색 정적 배지(`bg-ef4444`)
5.2 **버튼 상태 피드백**:
   - 전송 중 시: 버튼 클릭 비활성화(`disabled`), 동기화 아이콘 회전 애니메이션(`animate-spin`) 적용
   - 서버 오프라인 시: 메인 전송 버튼 비활성화 처리
