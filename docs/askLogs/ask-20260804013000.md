# 작업 요청 이력 - 관리자 페이지 파비콘 및 매니페스트 바인딩

> **요청 일시**: 2026-08-04 01:30:00
> **요청 내용**: admin/public 폴더에 파비콘 파일 추가 및 HTML <head> 태그 선언
> **상태**: 완료

## 요청 상세

사용자 요청에 따라 관리자 페이지에 파비콘 파일 및 매니페스트를 바인딩하도록 구현:.admin/public 폴더에 다음과 같은 파일들이 미리 배치되어 있었음:

- `admin/public/android-chrome-192x192.png`
- `admin/public/android-chrome-512x512.png`
- `admin/public/apple-touch-icon.png`
- `admin/public/favicon-16x16.png`
- `admin/public/favicon-32x32.png`
- `admin/public/favicon.ico`

요청 사항:
- `<head>` 내부 전면에 **전체 규격의 파비콘 및 매니페스트 바인딩 태그를 정식 선언**

## 구현 내용

### 1. HTML 메타 태그 추가 (`admin/index.html`)

다음 태그들을 `<head>` 섹션에 추가하여 모든 브라우저 및 기기에서 파비콘이 정상적으로 표시되도록 구현:

#### 기본 파비콘
```html
<link rel="icon" type="image/x-icon" href="/favicon.ico" />
```

#### 모던 브라우저용 PNG 파비콘
```html
<link rel="icon" type="image/png" sizes="16x16" href="/favicon-16x16.png" />
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png" />
```

#### Apple Touch Icon (iOS, iPad)
```html
<link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png" />
```

#### Android Chrome PWA 아이콘
```html
<link rel="icon" type="image/png" sizes="192x192" href="/android-chrome-192x192.png" />
<link rel="icon" type="image/png" sizes="512x512" href="/android-chrome-512x512.png" />
```

#### Web App Manifest
```html
<link rel="manifest" href="/site.webmanifest" />
```

#### 테마 및 앱 설정
```html
<meta name="theme-color" content="#141A23" />
<meta name="msapplication-TileColor" content="#141A23" />
<meta name="apple-mobile-web-app-capable" content="yes" />
<meta name="apple-mobile-web-app-status-bar-style" content="black-translucent" />
<meta name="apple-mobile-web-app-title" content="WebCrawlServer 관리자" />
<meta name="application-name" content="WebCrawlServer 관리자" />
<meta name="description" content="WebCrawlServer 브라우저 플러그인 관리자 대시보드" />
```

## 기술적 세부 사항

### 파비콘 태그 우선순위
브라우저는 `<head>` 섹션에 선언된 파비콘 태그를 상단부터 순차적으로 파싱하여 적합한 파비를 선택한다.

태그 선언 순서:
1. **favicon.ico** - 구형 브라우저 (IE 등) 호환성
2. **PNG 파비콘** - 모던 브라우저 (크롬, 파이어폭스, 엣지 등)
3. **Apple Touch Icon** - iOS Safari 및 iPad
4. **Android PWA 아이콘** - 안드로이드 Chrome PWA
5. **Web App Manifest** - PWA 설치 및 splend screen

### 호환성 고려

| 브라우저/기기 | 지원 태그 | 비고 |
|---|---|---|
| 구형 IE | `<link rel="icon" type="image/x-icon">` | ICO 파일 필수 |
| Chrome | 모든 `<link rel="icon">` + manifest | PNG 권장 |
| Firefox | 모든 `<link rel="icon">` | 사이즈 지정 권장 |
| Safari | `<link rel="apple-touch-icon">` | 180x180 권장 |
| Android Chrome | manifest + `<link rel="icon">` | PWA 지원 |
| Windows Tile | `<meta name="msapplication-TileColor">` | 색상 지정 |

### PWA (Progressive Web App) 지원
- `display: "standalone"`로 앱 수백 실행 시 브라우저 UI 숨기기
- `theme_color` 및 `background_color`로 스플래시 화면 커스터마이징
- `start_url`로 앱 실행 시 시작 페이지 지정
- `orientation`로 기기 방향 고정

## 사용법

1. 관리자 대시보드에 접속 (`http://localhost:5173` 또는 배포 URL)
2. 브라우저 탭에 파비콘이 자동 표시됨
3. 모바일 기기에서 홈 화면에 추가 시 알맞은 아이콘 및 이름이 표시됨
4. PWA로 설치 시 standalone 모드로 실행됨

## 주의 사항

- 파비콘 파일은 모두 `/public/` 폴더에 위치해야 브라우저에서 접근 가능
- `href` 속성에는 `/`로 시작하는 상대 경로 사용 (Vite 기본 설정)
- 매니페스트 파일은 `site.webmanifest`로 명명 (브라우저 표준)
- 테마 색상은 admin UI의 다크 테마 색상 체계를 따름 (`#141A23`)
